# My Portfolio

A personal portfolio site built with React, showcasing my projects and background as a Java backend developer.

## About

I'm Vivekanand Sharma, a Java backend developer with experience in Java, Spring Boot, Hibernate, and SQL. This portfolio was also a hands-on way for me to learn React by building something real, rather than following a tutorial.

## Features

- 📱 Responsive layout
- 📄 Resume viewing and download
- 💼 Project showcase with links to GitHub repos
- ✉️ Contact section with direct links

## Tech Stack

- [React](https://react.dev/) 19
- [Vite](https://vitejs.dev/) — build tool and dev server
- Plain CSS with custom properties (no CSS framework)
- ESLint for code linting

## Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/Vivekanand02/my-portfolio.git
cd my-portfolio
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
